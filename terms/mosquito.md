## What Mosquito does

It is a joke. It replies to a few keywords, reacts to messages at random, and answers when mentioned. It is normally only switched on for around April 1 and is not running for the rest of the year.

What it reads and what it does not keep is described in the [privacy policy](../privacy/mosquito.md), which you can also reach by running `/privacy` in the server.

**You can switch it off.** Anyone can run `/zap` in a channel to silence it there for fifteen minutes. Moderators can exclude channels entirely. If it is bothering you, say so to the moderation team.
